# پیش‌نمایش وب صفحه سرورها

نمونه مستقل و موقت رابط سرورها است، نه نسخه وب عملیاتی v2rayNG. همه گروه‌ها، نتیجه تست و اتصال ساختگی هستند؛ هیچ VPN، شبکه، کانفیگ، خروجی یا ذخیره‌سازی واقعی وجود ندارد. منطق حساس و حذف در اپ اندروید از این پیش‌نمایش مستقل است؛ حذف دسته‌ای ایمن و Undo در اندروید هنوز تکمیل نشده‌اند.

برای اجرا از ریشه مخزن:

```sh
python3 -m http.server 8768 --bind 0.0.0.0 --directory docs
```

سپس با مرورگر به ریشه سرور بروید. بدون سرویس خارجی یا بسته npm است.
